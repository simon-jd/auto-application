# Dot tools over the persistent Ubuntu backend

Approved scope: keep the existing Linux job library, add query/detail/manual-status
tools and a Skill, and connect Dot directly to Ubuntu without a running Mac.

1. Add a small `AgentService` over read-only `QueryService` and the existing
   decision/review semantics. A write updates one job and its review atomically;
   repeated requests are idempotent. No application submission or model invocation.
2. Expose context, search, detail and manual status through the official MCP Python
   SDK, stdio and loopback Streamable HTTP. Test with real MCP clients, temporary
   databases, rollback, duplicate requests and Canada exclusions.
3. Supply a concise job-search Skill and cloud plugin bundle bound to an actual
   registered ChatGPT app. Do not put a local MCP manifest in the cloud bundle.
4. Deploy a separate Ubuntu user service on 127.0.0.1:8767. Keep ingestion and
   runtime preferences intact. Test production reads and isolated database writes.
5. Configure OpenAI Secure MCP Tunnel on Ubuntu, register the private ChatGPT app,
   install its cloud Skill, and test from Dot. Account login and runtime tunnel
   credentials are required for this last stage. Report backend readiness and
   confirmed cloud connectivity separately.

Existing user constraints remain: exclude Canada in ordinary searches, preserve
source evidence and decisions, do not create mailbox OAuth applications, and do
not commit or push without a request.
