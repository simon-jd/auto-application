# Discord「等你回复」频道：操作流程

服务器上的 Claude 做材料时，遇到只有你能决定的事，会把问题发到这个频道。例如：通用岗位要不要投、走哪个方向；入职早于毕业还投不投；全程禁止 AI 的申请要不要做。每个问题一条消息，附语境和 Claude 的推荐。你点按钮或写一句话回复，Claude 几秒内接着处理，做完把职位交给 Grok。

## 一、第一次设置（只做一次）

### 1. 建频道

1. 在 Discord 里打开你的服务器，频道列表上点"+"（手机上点服务器名 → 创建频道）。
2. 选"文字频道"，名字比如"等你回复"，创建。
3. 如果频道设成了私密，要在频道设置的"权限"里把 bot 加进来，并允许这几项：
   - 查看频道
   - 发送消息
   - 嵌入链接
   - 读取消息历史（bot 在你的问题下面回复"已处理"时要用）

   公开频道一般不用改。

### 2. 拿到频道 ID

1. Discord 用户设置 → 高级 → 打开"开发者模式"。
2. 右键这个频道（手机上长按）→"复制频道 ID"。复制到的是一串数字。

### 3. 把频道 ID 写进服务器

这个文件里有 bot 的密钥，Claude 不读也不改，要你自己写。在 Mac 的终端里：

```bash
ssh home-ubuntu
```

登录服务器后，用编辑器打开 bot 的配置文件：

```bash
nano ~/Desktop/job-search/runtime/credentials/bot.env
```

在最后加一行，把数字换成刚才复制的频道 ID：

```text
AUTO_APP_DISCORD_QUESTIONS_CHANNEL_ID=123456789012345678
```

按 Ctrl-O 回车保存，Ctrl-X 退出。nano 会保留原来的文件权限（600），不用改。然后重启 bot：

```bash
systemctl --user restart auto-app-bot.service
```

```bash
systemctl --user is-active auto-app-bot.service
```

显示 `active` 就好了。显示 `failed` 时看报错：

```bash
journalctl --user -u auto-app-bot.service -n 20 --no-pager
```

报错会说哪一项写错了，常见的是 ID 里混进了空格或字母。

不加这一行也能用，问题会发到现在接收职位推送的那个频道。

## 二、平时怎么用

### 一条问题消息长这样

- **标题：** `#编号 公司 — 岗位`，点标题打开职位页面。
- **正文：** 问题（加粗），下面是语境，比如 JD 原句、冲突在哪、Claude 查到了什么，最后是"Claude 推荐：……"。
- **按钮：**
  - **每个可选答案一个按钮**（绿色），例如"投，infra/distributed_systems 方向""投，sde 方向"。
  - **其他回复…**（蓝色）：弹出输入框，用你自己的话回答，最多 1000 字。例如"投，但 cover letter 别提 Rust"。
  - **不投**（灰色）：直接把这个职位记为不投，不用再等 Claude。
- 只有你本人能点。别人点了会看到"Owner only"。

### 点了之后会发生什么

1. Discord 给你一条只有你看得到的确认："已记下你的回复……"，消息上的按钮随之消失。
2. 服务器几秒内启动 Claude，按你的回答接着做，比如从第二阶段继续做简历和求职信，审阅后发布。一般要十几分钟。
3. 做完后 bot 在你的问题下面回复一句，例如"#30226 已处理：按 infra 方向做完材料并发布，已进入投递队列，Grok 下一轮会填表"。
4. Grok 的例行任务每 15 分钟一轮，会认领这个职位、填表、hold 住，然后在 Grok 对话里把填好的表列给你，等你说"提交 #编号"。

点了"不投"的，问题下面会出现"已处理：已记为不投，不再处理。"，到此结束。

### 其他情况

- **Claude 觉得你的回答还不够做决定：** 它会再发一个更具体的问题，在问题下面回复"还需要你回答一个问题，已发在频道里"。
- **你的回答要它做材料以外的事**（改设置、改搜索等）：它不会做，回复里会写明。这类事在手机的 Claude App 里用 Remote Control 跟服务器上的 Claude 说。
- **同一个问题不会重复出现：** 没回答之前，Claude 每次检查都会再问一遍，但服务器不会重复发。
- **`/pause` 不影响这个频道：** 暂停的是职位推送，问题照常发。

## 三、哪些问题会出现在这里，哪些不会

| 会出现在这个频道（Claude 的问题） | 不在这里（Grok 的问题，在 Grok 对话里问你） |
|---|---|
| 做材料第二阶段停下：通用岗位、方向不明、入职早于毕业、不是应届生岗位、全程禁止 AI 等 | 填表时速查表没有的事实：下拉框没有对应选项、成绩单、offer 详情 |
| 修改意见里 Claude 没执行的 | `[本人填写]` 的题：要你用自己的话写的回答 |
| 要你确认的事实 | 提交前的确认："提交 #a #b" |

## 四、出问题时

- **消息一直没出现：** bot 每 5 分钟检查一次，先等 5 分钟。还没有，就在服务器上运行 `systemctl --user is-active auto-app-bot.service`，确认 bot 在运行。
- **点按钮没反应：** 确认你用的是 `bot.env` 里那个 owner 账号。
- **问题下面一直没有"已处理"：** 在 Grok 里用 `jobq status <编号>`，或者在 Remote Control 里问服务器上的 Claude"#编号到哪一步了"。
