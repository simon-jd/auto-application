# Dot tools and shared manual application tracking — 2026-10-10

**Step:** 4  **Status:** Ubuntu services deployed; private cloud tools and Skill installed; cloud MCP reads verified on 2026-10-11

Added a separate `auto-app-agent` MCP entry point with four tools: context,
paginated job search, job details, and explicit manual application status.
Queries use the existing read-only service and shared Canada exclusion.
Manual decisions, review evidence and implied feedback use one transaction;
repeated current status/reason calls are idempotent. Applied state cannot be
rolled back by this interface. No website submission is performed.

The adapter uses the official MCP Python SDK 2.3 already present in the lockfile,
now declared directly. `MCPServer` is the official SDK's replacement for the v1
`FastMCP` name. It supports stdio and loopback Streamable HTTP; public binding
is rejected. Three tools are marked read-only; the write tool has explicit
annotations and reports expected validation errors through MCP.

The source Skill and plugin builder bind a cloud plugin to the actual registered
ChatGPT app through `.app.json`. A separate skills-only bundle is instructions
only. Ubuntu service templates live in `deploy/`; the [setup guide](../dot-setup.md)
documents the private outbound tunnel and the cloud acceptance checks.
